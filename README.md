# TDK CLI releases

Public binary releases for TDK CLI.

The CLI source lives in a private repository. This repository only hosts release assets:

- `tdk-linux-amd64`
- `tdk-linux-arm64`
- `tdk-darwin-amd64`
- `tdk-darwin-arm64`
- `checksums.txt`

Install:

```sh
curl -fsSL https://tdk-landscape.github.io/install.sh | sh
```
